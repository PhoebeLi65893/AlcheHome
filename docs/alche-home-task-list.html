Local test environment (Windows)

Set up once, used by every "run pytest" step
  1. Install Docker Desktop and Python 3.12 (winget install Python.Python.3.12). Use 3.12, not 3.14: some pinned packages have no Windows wheels for 3.14 yet. py -0p lists the Pythons you have.
  2. Create the virtual environment in core-api: cd C:\Users\liche\AlcheHome\core-api, py -3.12 -m venv .venv
  3. Allow the activation script for this window only: Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass, then .\.venv\Scripts\Activate.ps1 Expected: the prompt starts with (.venv) and python --version says 3.12.x.
  4. Install dependencies: pip install -r requirements-dev.txt
  5. Start the database from the project root: docker compose up -d --build
  6. Point the tests at it: $env:DATABASE_URL="postgresql+psycopg://alche:alche@localhost:5432/alche", then pytest Expected: everything passes with nothing skipped. A skipped count means DATABASE_URL is not set or the database is not running.
  7. Each new PowerShell window needs the Set-ExecutionPolicy, Activate.ps1 and DATABASE_URL lines again.
Troubleshooting
SymptomCause and fix
ModuleNotFoundError: No module named 'fastapi' when running pytestpytest is using the system Python, not the project's virtual environment. Create and activate the .venv (steps above), run pip install -r requirements-dev.txt, and check python --version says 3.12.x.
Activate.ps1 cannot be loaded ... is not digitally signedPowerShell blocks scripts by default. Run Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass (this window only), or permanently for your user: Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned. With no policy change, call the venv directly: .\.venv\Scripts\python.exe -m pytest.
failed to connect to the docker API at npipe:////./pipe/docker_engineDocker Desktop is not running. Start it and wait for "Engine running", then retry in a new window. Check docker version shows a Server section.
500 Internal Server Error ... dockerDesktopLinuxEngine/_pingThe engine is still starting or its WSL 2 backend is broken. Wait 2-3 minutes; then quit Docker Desktop, run wsl --shutdown and wsl --update, and start it again. Also try docker context use desktop-linux. Last resort: Troubleshoot (bug icon) > Restart, or Clean / Purge data. Virtualization must be enabled in the BIOS.
Terraform: could not find default credentialsTerraform needs Application Default Credentials, a separate login from gcloud auth login. Run gcloud auth application-default login, then gcloud config set project YOUR_PROJECT_ID and gcloud auth application-default set-quota-project YOUR_PROJECT_ID.
Chat always answers "Sorry, I'm having trouble right now..."The Gemini call is failing. Run docker compose logs core-api --tail 30 and find the line Gemini call failed: .... HTTP 400 or 403: the key is wrong or restricted (check .env has no quotes or spaces, then docker compose up -d). HTTP 404: the model name is retired (gemini-2.5-flash was shut down in October 2026). Set GEMINI_MODEL in .env to a current one, then docker compose up -d. To list what your key can use: (Invoke-RestMethod -Uri "https://generativelanguage.googleapis.com/v1beta/models" -Headers @{"x-goog-api-key"=$key}).models.name HTTP 429: free-tier quota reached, wait or enable billing. empty response / MAX_TOKENS / blockReason: the model returned no text. ConnectError or Timeout: the container cannot reach generativelanguage.googleapis.com.
SMS replies never arrive (T9)Run docker compose logs core-api --tail 30 and look for Could not send SMS reply. 21608: trial accounts can only text verified numbers (verify yours in the Twilio console, or use the Virtual Phone). 30034: texting real US phones from a 10-digit number needs A2P 10DLC registration. SMS not sent ... not configured: TWILIO_ACCOUNT_SID or TWILIO_FROM_NUMBER is missing. 403 in ngrok: PUBLIC_BASE_URL must exactly match the URL configured in Twilio (and changes each time free ngrok restarts).
curl prints a security prompt or HTML in PowerShellcurl is an alias for Invoke-WebRequest there. Use curl.exe or Invoke-RestMethod.
